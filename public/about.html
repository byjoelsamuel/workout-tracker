About

Tsyoku-naru

"Get stronger." A small, personal workout tracker.

What this is

Tsyoku-naru is a personal project for tracking workouts: allowing users to create a profile, log exercises by body group, and watch a body map fill in with orange as training volume builds up for each muscle group.

How it works

There's no account system and no server — every profile and exercise log is saved to this browser's storage. That keeps things simple, but it also means your data lives on whichever device you used to log it, not in the cloud.

Built with

Plain HTML, CSS, Claude API and JavaScript. Source at github.com/byjoelsamuel/workout-tracker.
